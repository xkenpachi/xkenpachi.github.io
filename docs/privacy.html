Privacy Policy

Last Updated: October 7, 2025

1. Introduction

MiniPost Pro (“we”, “our”, or “us”) values your privacy. This Privacy Policy explains how your information is handled when using our macOS application.

2. Data Collection

  • Personal Data: We do not collect, store, or share any personal information.
  • Usage Data: MiniPost Pro runs entirely offline. No analytics, crash reports, or telemetry data are collected.
  • Network Requests: All requests are initiated manually by the user and sent directly to external APIs defined by the user.

3. Local Data Storage

MiniPost Pro may store request history, environment variables, and settings locally on your Mac. This data never leaves your device.

4. Data Sharing

We do not share or transmit any data to third parties. All API requests and responses remain on your local device.

5. Security

All outgoing API requests use HTTPS encryption provided by macOS. Sensitive data such as API keys are stored securely on your device only.

6. User Rights

Since no personal data is stored on our servers, all app data can be deleted by uninstalling MiniPost Pro.

7. Compliance

  • GDPR: Compliant — no personal data processing or tracking occurs.
  • CCPA: Compliant — no user data is sold, shared, or monetized.

8. Contact

For questions about this policy, contact us at: support@minipostpro.app

Gizlilik Politikası

Son Güncelleme: 7 Ekim 2025

1. Giriş

MiniPost Pro (“biz”, “uygulama” veya “geliştirici”) olarak gizliliğinize önem veriyoruz. Bu sayfa, uygulamamızı kullanırken verilerinizin nasıl işlendiğini açıklar.

2. Veri Toplama

  • Kişisel Veri: Herhangi bir kişisel bilgi toplamaz, saklamaz veya paylaşmayız.
  • Kullanım Verisi: MiniPost Pro tamamen offline çalışır. Hiçbir analiz, çökme raporu veya telemetri verisi toplanmaz.
  • Ağ İstekleri: Tüm istekler kullanıcı tarafından başlatılır ve yalnızca kullanıcının tanımladığı harici API’lere gönderilir.

3. Yerel Veri Saklama

Uygulama, istek geçmişi, ortam değişkenleri ve ayarları cihazınızda yerel olarak tutabilir. Bu veriler cihaz dışına çıkmaz.

4. Veri Paylaşımı

Üçüncü taraflarla hiçbir veri paylaşımı yapılmaz. API istekleri ve yanıtları tamamen yerel olarak saklanır.

5. Güvenlik

Tüm API istekleri macOS’un sağladığı HTTPS şifrelemesiyle güvenli şekilde iletilir. API anahtarları gibi hassas bilgiler yalnızca cihazınızda güvenli şekilde saklanır.

6. Kullanıcı Hakları

Sunucularımızda hiçbir kişisel veri tutulmadığından, uygulamayı kaldırarak tüm verilerinizi kalıcı olarak silebilirsiniz.

7. Uyumluluk

  • GDPR: Uyumlu — hiçbir kişisel veri işleme veya izleme yapılmaz.
  • KVKK: Uyumlu — kullanıcı verileri toplanmaz, paylaşılmaz veya satılmaz.
